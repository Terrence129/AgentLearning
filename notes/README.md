# Notes

Your own thinking lives here — this is the part of the repo that is not generated.

One file per week, created from [`../templates/weekly-review.md`](../templates/weekly-review.md):

```
notes/week01-review.md
notes/week02-review.md
...
notes/week00-baseline.md
notes/decisions/          # one-page ADRs for choices you want to defend
```

## Why this matters

Writing is the cheapest form of retrieval practice. A review you can re-read in three months is worth more than any certificate, and it is the raw material for the portfolio posts in week 9.

## Rules

- Fill the **"explain it in 150 words"** section *without* looking at notes. Then fix it.
- Record **dead ends** — they are the most valuable part and the most likely thing you will forget.
- Record **cost and time spent**; it calibrates future estimates.
- One screen maximum. If it is longer, it is a draft for a blog post — move it to `projects/portfolio/`.
